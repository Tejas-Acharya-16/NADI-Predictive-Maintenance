# Pipeline map

`cmapss_data.py` reads and validates raw whitespace-delimited telemetry and builds training RUL labels. `approaches/rolling_features.py` creates current, trailing mean, standard deviation, lag-difference, and trailing-slope features per engine. `approaches/feature_variants.py` fits feature choices on development engines and transforms held-out engines causally. `run_fd001_grouped_audit.py` performs five-fold engine-grouped pseudo-censored validation without opening official-test files. `run_fd001_sequence_study.py` contains bounded CNN/LSTM/CNN-LSTM comparisons. `run_anomaly_triage_demo.py`, `approaches/anomaly_detection.py`, and `triage.py` produce the separate anomaly and deterministic work-order demo. `evaluate_selected_fd001.py` is a separate, explicitly labelled historical official-test stage.
